Original work in this repo
--------------------------
Everything the player sees or hears is generated in this repository and
ships as code, not as assets:

  src/ui/terrainArt.ts   the board skin — hypsometric wash, north-west
                         relief, hedged parcels, furrows, drawn scrub and
                         ribbon roads, baked once on a Canvas 2D surface
                         and used as the terrain texture
  src/render/models.ts   every model on the field — infantry, cavalry,
                         field guns, trees, cottages, forts, redoubts and
                         depots — cut from primitives in code and welded
                         into instanced meshes
  src/render/board.ts    the 3D board itself: displaced terrain, water,
                         fog veil, camera and lighting
  src/ui/overlay.ts      borders, supply routes, works, formations,
                         tracers, fog and banners, drawn per frame
  src/audio/sound.ts     every sound in the game, synthesised at runtime
                         through the Web Audio API — bugle calls over a
                         natural harmonic series, filtered noise for
                         volleys and cannon, a convolution reverb built
                         from a decaying noise burst, and distance
                         modelled as gain, air absorption and reverb send

No sample libraries, model files, texture files or image assets are shipped.
public/ contains a favicon, two Cloudflare routing files and these notices.

Removed from earlier builds
---------------------------
An earlier first-person build carried postprocessing, n8ao and
@dgreenheck/ez-tree. All three were deleted along with every texture,
model and license that supported them, and nothing from those packages
remains in the source tree, the dependency list or the shipped bundle.
three.js stayed: the game is now a top-down real-time strategy board and
still renders through it.
